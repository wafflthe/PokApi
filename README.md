# PokApi

An API for keeping track of your pokemon card collection!!
Stores data for card, set, set number, condition, and estimated value
(Utilizes API keys for authentication)

Register a new user and get an api key: /register

Shows current collection of all cards uploaded: /collection

Allows a new card to be added to the database: /add

Allows either est value or condition or both for a card to be updated based on id: /update/{card_id}

Allows a card to be deleted from the database based on id: /delete/{card_id}

Shows all estimated values combined for a total collection value: /total_value
